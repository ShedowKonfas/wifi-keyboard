# wifi-keyboard

Веб-пульт управления ПК с телефона или другого устройства в сети: кнопки мыши, клавиши, системные хоткеи, яркость монитора и стрелки плеера. Сервер поднимается на PyWebIO, порт `1337`.

## Быстрый старт

```bat
python -m venv venv
venv\Scripts\pip install -r requirements.txt
start.cmd
```

Далее откройте `http://<ip вашего ПК>:1337` (с самого ПК — `http://127.0.0.1:1337`). `start.cmd` запускает `venv\Scripts\python.exe main.py` и оставляет консоль открытой.

## Возможности

- Мышь: ЛКМ, ПКМ, средняя кнопка, двойной клик.
- Клавиатура: Enter, Space, Backspace, Tab, Esc + стрелки для плеера.
- Меню: «Свернуть всё» (`Win+D`), «Диспетчер задач» (`Ctrl+Shift+Esc`), обновление страницы.
- Монитор: яркость `-10%`, `+10%`, `100%` через `screen-brightness-control` (главный монитор).

При запуске скрипт ждёт 2 секунды и сам сворачивает все окна (`Win+D`), чтобы пульт был виден.

## Настройки

Порт и режим `debug` заданы в конце `main.py`: `start_server(main, port=1337, debug=True)`. Зависимости: `pywebio`, `screen-brightness-control`, `pyautogui`.

## Безопасность

Авторизации нет: любой, кто попадёт на порт 1337, может нажимать клавиши и кликать мышью на вашем ПК. Не пробрасывайте порт наружу.

## Структура

| Файл | Роль |
|---|---|
| `main.py` | обработчики кнопок, вёрстка пульта, запуск сервера |
| `requirements.txt` | три зависимости |
| `start.cmd` | запуск через venv |
| `wifi-kb.cmd.lnk` | ярлык для быстрого запуска |

## Тесты

Автотестов нет; проверка вручную — открыть страницу и нажать, например, «ЛКМ» или «🔆 +».
