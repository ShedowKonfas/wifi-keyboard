# AGENTS.md — wifi-keyboard
## Назначение
Веб-пульт для Windows-ПК с телефона: PyWebIO на порту 1337, кнопки мыши/клавиатуры и яркость монитора.
## Карта файлов
- `main.py` — `screen_brightness()`, `on()`, `on_mouse()`, `hotkeys()`, `strelki()`, `main()`, `start_server(port=1337, debug=True)`.
- `requirements.txt` — `pywebio`, `screen-brightness-control`, `pyautogui`.
- `start.cmd` — запуск через `venv\Scripts\python.exe` (без fallback).
- `wifi-kb.cmd.lnk` — ярлык; `README.md`, `AGENTS.md` — документация.
## Запуск и тесты
```bat
python -m venv venv
venv\Scripts\pip install -r requirements.txt
start.cmd
```
Адрес: `http://127.0.0.1:1337` или `http://<ip ПК>:1337`. Тестов нет; проверка вручную — нажать кнопку.
## Соглашения
- Новые кнопки — `put_button(...)` в `main()`, обработчик — отдельная функция.
- Подписи интерфейса — на русском.
- Порт и авторизацию не меняем без обсуждения.
## Подводные камни
- При старте выполняется `Win+D`: сворачивание окон — штатное поведение.
- Обработчики реально управляют ПК; яркость берётся с первого монитора.
- Нет аутентификации: порт 1337 нельзя открывать во внешнюю сеть.
